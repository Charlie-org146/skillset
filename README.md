## 1. One format for every song

Every song is written to the same song file and printed through one template, so a change to the template changes every song the same way, and the same song file gives the same printout.

Enforced by: BAS-1, BAS-10, BAS-4

## 2. The whole song at a glance

One compact printout of at most two pages shows the sections, repeats, chords, lyrics, tempo and key, with the header filled in.

Enforced by: BAS-2, BAS-3, BAS-7

## 3. Only what the sources show

Each bar, chord and lyric comes from a source the owner provided and can be traced to it, a missing or estimated part is reported, and no text is silently turned into question marks.

Enforced by: BAS-6, BAS-8, BAS-5

## 4. It fits the player's bass

The tab draws as many string lines as the song's bass has, labeled to match its tuning.

Enforced by: BAS-9
